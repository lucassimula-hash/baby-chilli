# Chilli Composition Examples

These examples show approved ways to compose public Chilli components.

They import from `../index`, the current local public entry point.

## Examples

- `campaign-list.tsx`: a mobile campaign feed using `CampaignCard`, `AvatarGroup`, and `Button`.
- `campaign-page.tsx`: a campaign detail composition with page navigation, action cards, progress and social proof.
- `action-form.tsx`: an action creation form using action-specific inputs and navigation.
- `empty-state.tsx`: a compact empty state using only public primitives.

Run the documentation consistency check after editing examples:

```bash
npm run check:docs
```
